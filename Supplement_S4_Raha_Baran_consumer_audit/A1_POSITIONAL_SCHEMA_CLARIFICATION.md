# A1: positional schema operational clarification

Recorded after the first native attempt. That attempt completed flights, rayyan, tax and toy with zero raw-versus-native label differences, while the wrapper rejected beers, hospital and movies_1 before calling the native Dataset constructor because their clean and dirty header names differ. All pairs have matching row and column counts. The failed attempt, completed cases, script and actual invocation receipt are preserved in initial_strict_header_attempt.

The root-frozen protocol uses the official positional comparison contract; it never required identical column names. Dataset.get_dataframes_difference compares positional .values and then uses .iloc. The wrapper's hd==hc precondition was therefore unnecessarily strong for the frozen endpoint. A1 removes that wrapper-only requirement, retains original clean and dirty headers separately and requires equal dimensions, and compares each native table to the independently parsed corresponding source. No semantic mapping is inferred from approximate header names. This reports what the native position-defined evaluator does; it does not authenticate entity identity or prove semantic column alignment.

The native source is unchanged. All seven cases are rerun once as deterministic read/score/export operations to obtain a uniform receipt after this adapter correction. No upstream generator, detector, model, stochastic process, dataset substitution or seed selection is involved. First-attempt results remain preserved. E1–E4 and the seven-pair census are unchanged. Results requiring this clarification are reported with this chronology, not as an untouched first attempt.

Separately, static independent review found re.sub's fourth argument is count, so literal upstream re.UNICODE means count=32. The previously unexecuted independent implementation was corrected to count=32 before its first execution. The semantic correction receipt is retained. No upstream normalization repair or unlimited-replacement endpoint is introduced.
